# Project automation

Mac distribution was retired on October 26, 2026. The macOS release and Homebrew smoke-test workflows have been removed. Tags no longer trigger Mac packaging, GitHub Release publishing, or automatic cask updates.

The Homebrew cask is deprecated and pinned to the final Mac release, 1.2.0. Existing GitHub Release downloads remain available and unsupported.

The security-check workflow remains active. There is no iOS release or TestFlight workflow yet.

## Legacy Mac tools

Mac source, local build commands, screenshot tools, installer, release-note helper, and cask-update helper remain for historical use. They are not an active release process. Do not follow older instructions to tag and publish a Mac release.

For source projects and current installation instructions, see [README.md](README.md).
